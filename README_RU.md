# Конвертер MAA → Fairbeam JSON

**Пакетный конвертер антенных моделей MMANA-GAL / MMANA (`.maa`) в проекты Fairbeam (`.design.json`)**

**Версия:** 1.2.2 — Port Topology Guard  
**Автор:** UA1CFM · © 2026  
**Платформы:** Windows 10/11 (графический интерфейс / автономный EXE); Python 3.9+ (командная строка при наличии окружения)  
**Языки описания:** [English](README.md) · [Русский](README_RU.md)

## Назначение программы

MAA → Fairbeam JSON Converter переносит геометрию проводных антенн и поддерживаемые электрические элементы из файлов MMANA в формат `fairbeam.design/1`. Программа способна обработать целую библиотеку антенн, сохранить структуру вложенных папок и сформировать подробный отчёт.

Конвертер предназначен для радиолюбителей и разработчиков антенн, использующих MMANA и желающих просматривать, дорабатывать и исследовать модели в Fairbeam/openEMS.

**Важно:** успешно созданный JSON **не гарантирует** электрической эквивалентности исходной модели MMANA. Если источник или нагрузку нельзя безопасно перенести, конвертер сохраняет диагностическое предупреждение. Перед использованием результатов необходимо проверить порт, сетку и качество расчёта непосредственно в Fairbeam.

## Возможности

- **Пакетная конвертация с обходом подпапок:** `.maa` → `.design.json` с сохранением дерева каталогов.
- **Графическое приложение:** выбор входной и выходной папок, прогресс, предупреждения, остановка после обработки текущего файла.
- **Командная строка** для автоматизации.
- **Геометрия:** перенос координат и индивидуальных радиусов проводников. Если в MMANA заданы разные диаметры, они сохраняются.
- **Частоты:** преобразование МГц в ГГц, формирование полосы расчёта вокруг частоты исходной модели.
- **Источники:** перенос поддерживаемых осевых источников в реальные разрывы с линейными lumped-портами; опорное сопротивление по умолчанию — 50 Ом.
- **Проверка опасных портов:** выявление ряда случаев, когда соседний металл пересекает или перекрывает область порта. Неоднозначный порт отклоняется вместо создания заведомого короткого замыкания.
- **Нагрузки:** поддерживаемые варианты R, L, C и RLC. Нулевые параметры не записываются в поля, которые Fairbeam требует положительными. Конечная добротность Q представляется приближённым эквивалентом на рабочей частоте.
- **Протокол:** сведения об исходных источниках, нагрузках, предупреждениях и состоянии модели в `_maa_conversion`; отчёт `conversion_report.csv`.
- **Сборка для Windows:** `BUILD_EXE_WINDOWS.bat` с использованием PyInstaller.

## Установка и запуск в Windows

1. Скачайте и распакуйте архив версии.
2. Для запуска из исходников установите **Python 3.9+ с Tkinter** и запустите `maa_to_fairbeam.py`.
3. Либо запустите **`BUILD_EXE_WINDOWS.bat`**: он устанавливает необходимые зависимости, выполняет тесты и собирает `Windows_EXE/MAA_to_Fairbeam_JSON.exe`.
4. Выберите папку с MAA-файлами и **отдельную** выходную папку.
5. Укажите расширение `.design.json`, настройте перезапись и нажмите **Convert all MAA → JSON**.
6. Изучите `conversion_report.csv`, откройте полученные проекты в Fairbeam и проверьте источники, нагрузки, сетку, S11 и состояние расчёта.

Для сборки EXE требуются Windows, Python (или поддерживаемая автоматическая установка) и интернет для получения PyInstaller. **В исходном ZIP готового EXE нет.**

## Работа из командной строки

```powershell
python maa_to_fairbeam.py --input "C:\Antennas\MAA" --output "C:\Antennas\Fairbeam"
```

Основные параметры:

```text
--suffix .design.json       Расширение выходного файла
--overwrite                Перезаписывать существующие JSON
--port-r 50                Опорное сопротивление порта, Ом
--radius-zero-mm 0.5       Радиус по умолчанию при нулевом радиусе в MAA
--sweep-percent 5          Полоса расчёта ±5% от исходной частоты
```

Полный список — `python maa_to_fairbeam.py --help`.

## Пример структуры папок

```text
MAA_collection/
  VHF/
    Yagi.maa
  Loops/
    Loop.maa

Fairbeam_collection/
  VHF/
    Yagi.design.json
  Loops/
    Loop.design.json
  conversion_report.csv
```

В JSON добавляется раздел `_maa_conversion` с исходными записями об электрических элементах и результатами их преобразования.

## Известные ограничения

- Импульсы MMANA `WnB`, `WnC`, `WnE` и смещения, особенно при автоматической сегментации, **не всегда однозначно переводятся** в геометрические позиции Fairbeam.
- Диагональные источники, пересечения проводников и сложные узлы питания могут требовать ручной реконструкции. Небезопасные порты отклоняются.
- Многоисточниковые схемы с фазировкой, модели земли, стеки антенн и некоторые согласующие цепи **не переносятся в полностью эквивалентном виде**.
- Даже `simulation_ready` и отсутствие ошибок предварительной проверки **не доказывают** правильную работу порта на сетке openEMS. Нужно проверять отсутствие `Port not coupled` в реальном расчёте.
- Тонкие геометрические детали могут приводить к очень мелкой сетке и длительному FDTD-расчёту.
- Иногда файл содержит только геометрию с предупреждениями. **Такой файл нельзя считать готовой электрической моделью.**

### Проверка на базе антенн

Версия 1.2.2 прошла пакетную обработку базы из **1713 MAA-файлов**: созданы **1713 JSON-проектов**, пройдены **30 автоматических тестов конвертера**. Это показатели обработки данных, **а не 1713 успешных электромагнитных расчётов Fairbeam**. Индивидуальные результаты находятся в `REGRESSION_1713_V122.csv`; модели с неполными источниками и нагрузками отмечены.

## Направление дальнейшей разработки

Основная задача — восстановление топологии импульсов MMANA, точное включение источников и нагрузок при автоматической сегментации, поддержка сложных питающих узлов и автоматическая проверка электрического сопряжения на сетке Fairbeam/openEMS. Приоритет — физическая корректность, а не просто успешная проверка JSON.
